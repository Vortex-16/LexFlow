# Prompt 03 — Documents + Compare

Implement document analysis and document comparison.

Requirements:
- validate file MIME/type/size,
- reject unsafe filenames and executable content,
- extract text with page metadata,
- detect headings/clauses,
- create coherent chunks,
- support question-answering against a document,
- align corresponding sections in two documents,
- classify changes as added/removed/modified,
- link every material difference back to source evidence.

Add unit, integration, and end-to-end coverage for the main document workflow.

Include synthetic fixtures only; do not add private legal documents.
