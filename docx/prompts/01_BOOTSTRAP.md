# Prompt 01 — Bootstrap

Read `01_MASTER_AGENT_PROMPT.md` through `12_DEMO_AND_SUBMISSION.md` before coding.

Task: bootstrap the repository only.

Requirements:
- preserve an existing working stack when practical,
- establish TypeScript strictness,
- establish lint/typecheck/test/build scripts,
- create `.env.example`,
- create initial Next.js shell if needed,
- create domain/application/infrastructure boundaries,
- create the first GitHub Actions CI workflow,
- create repository/branch guard scripts,
- keep the repository small.

Do not implement advanced AI behavior yet.

After coding: run lint, typecheck, unit tests, and build. Fix all failures. Then summarize files changed and why.
