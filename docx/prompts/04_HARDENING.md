# Prompt 04 — Security, Safety, Accessibility

Perform a hardening pass using the project pack as the contract.

Audit and fix:
- prompt injection in uploaded documents,
- citation spoofing,
- unsafe HTML rendering,
- upload abuse,
- path traversal,
- unauthorized document access,
- secret leakage,
- excessive logging,
- missing rate limits,
- weak error handling,
- keyboard accessibility,
- focus management,
- mobile usability.

Add or improve tests for every meaningful fix.

Do not merely add disclaimers. Enforce safety through validation, retrieval boundaries, output schemas, and deterministic rules.
